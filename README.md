# IssueAgent

IssueAgent is developed an AI-powered developer tool to help programmers check their programs for errors in their code and GitHub repositories. it helps the user understand what is causing them, and receive suggested fixes.

The project uses **NVIDIA Nemotron 3 Super 120B** through **Nebius Token Factory** to perform code analysis.

IssueAgent can:

- Analyse a single piece of code
- Analyse a public GitHub repository
- Identify potential errors and affected lines
- Suggest replacement code
- Monitor registered GitHub repositories using GitHub Webhooks
- Send analysis results through email
- Run through a Flask-based web interface

---

## NVIDIA Nemotron and Nebius Token Factory

IssueAgent uses:

**NVIDIA Nemotron 3 Super 120B**

Model:nvidia/nemotron-3-super-120b-a12b

The model is accessed through the **Nebius Token Factory OpenAI-compatible API**.

IssueAgent connects to:https://api.tokenfactory.nebius.com/v1/

Nebius Token Factory allowed us to integrate NVIDIA Nemotron into the application using an OpenAI, making it straightforward to send code and repository context to the model and receive structured analysis.

The Nemotron model is responsible for:

- Analysing submitted source code
- Detecting potential programming errors
- Identifying affected lines
- Explaining what caused the issue
- Suggesting replacement code
- Analysing the context of complete GitHub repositories

## How IssueAgent Works

### 1. Direct Code Analysis

Users can paste code directly into the application.

IssueAgent uses a structured prompt containing the submitted code and sends it to NVIDIA Nemotron through Nebius Token Factory.

The model is instructed to return:

- A short summary of the issue
- The affected line number or lines
- An explanation of the problem
- Suggested replacement code

If no errors are detected, the agent reports that no errors were found.

---

## 2. GitHub Repository Analysis

IssueAgent can also analyse an entire public GitHub repository.

The user provides a repository URL and IssueAgent uses **gitingest** to retrieve:

- The repository file structure
- Source files
- Codebase context

The repository content is then included in the prompt sent to NVIDIA Nemotron.

This allows the model to analyse code with more context than a single isolated code snippet.

If a README is present in the analysed repository, it can also be used as additional project context.

---
## 4. Web Interface

IssueAgent includes a Flask-based web interface.

The interface allows users to:

- Paste code for analysis
- Submit a GitHub repository URL
- View responses generated by NVIDIA Nemotron

# Using IssueAgent

## Analyse Code

1. Open the IssueAgent web interface.
2. Select the code analysis option.
3. Paste your source code.
4. Submit it.
5. NVIDIA Nemotron analyses the code through Nebius Token Factory.
6. The response shows detected problems and suggested fixes.

---

## Analyse a GitHub Repository

1. Open IssueAgent.
2. Enter the URL of a **public GitHub repository**.
3. Submit the repository.
4. IssueAgent retrieves its structure and code using gitingest.
5. The repository context is sent to NVIDIA Nemotron.
6. The analysis result is displayed in the web interface.

The repository must currently be publicly accessible for IssueAgent to retrieve it.

---

# Email Notifications

IssueAgent can send analysis results by email.

The AI agent is instructed to make the first line of its response a short summary of the detected issue.

This first line becomes the email subject.

Everything after the first line becomes the body of the email.

The program:

- Validates email addresses
- Allows email delivery to be skipped
- Stores the previously entered email address locally
- Allows the saved address to be reused

# Project Architecture

The core components of IssueAgent include: 

Connects to Nebius Token Factory and sends requests to NVIDIA Nemotron:Agent.py 

Handles direct code analysis: codeInput.py

Retrieves public GitHub repository content and sends the codebase context to the AI agent:checkRepo.py 

Runs the Flask web application and handles GitHub Webhooks and repository monitoring:app.py

Handles email delivery and email validation: sendEmail.py

Handles ntfy notifications: sendNotification.py

Starts the local Flask application: Main.py

# Why We Used Nebius Token Factory

Nebius Token Factory made it possible to use NVIDIA Nemotron through a simple OpenAI-compatible API.

This reduced the amount of infrastructure required to integrate the model into IssueAgent and allowed us to focus on building the developer workflow around the model.

Instead of hosting the model ourselves, IssueAgent can send repository and code context directly to the Token Factory endpoint and receive generated analysis.

This was particularly useful during development because the same API integration could be reused for:

- Individual code analysis
- Complete repository analysis
- Automated repository monitoring
